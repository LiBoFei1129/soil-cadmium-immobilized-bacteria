## 结果与研究内容解读
@cyz20030901图4为TP17菌株的系统发育树。该树基于16S rRNA序列构建，展示了TP17菌株与其他近缘菌株的系统发育关系。结果显示，TP17菌株与多株假单胞菌属（*Pseudomonas*）菌株（包括恶臭假单胞菌*Pseudomonas putida*、未培养假单胞菌*Uncultured Pseudomonas sp.*等）聚为同一大分支，其中与HM152688.1等未培养假单胞菌的亲缘关系最近，分支自举检验值（Bootstrap）为37，而假单胞菌属分支的根节点自举值达100，充分证明了该类群的进化可靠性；沙雷氏菌属（*Serratia*）菌株则形成独立的外类群分支，与假单胞菌属形成明显的进化区分。该系统发育树明确了TP17菌株的分类学地位，证实其归属于假单胞菌属，为其后续的功能研究（如重金属耐受、环境修复应用）提供了分类学依据。

@LiBoFei1129图5为TP17菌株在不同镉浓度胁迫下的生长曲线测定结果，该研究以0 mg·L⁻¹为空白对照，设置50~300 mg·L⁻¹共6个镉浓度梯度，以600 nm波长下的吸光度（OD₆₀₀ₙₘ）表征菌株生物量，连续监测96 h内菌株的生长动态，旨在探究TP17菌株对重金属镉的耐受特性，为其在镉污染土壤修复中的应用提供微生物学基础数据。
显示了TP17菌株在0、50、100、150、200、250、300 mg/L共7个镉浓度下的生长曲线：
- 镉浓度越高，菌株最大生物量（OD₆₀₀）越低，高浓度对生长有显著抑制作用
- 所有浓度组均呈现典型的延迟期、对数期、稳定期生长特征
- 误差棒代表3次生物学重复的标准误，数据重复性良好
- 结果验证了TP17菌株的镉耐受能力，为后续固定化菌株吸附土壤镉的研究提供基础

@tang7928 图12为MPS-T 在土壤中 5 次循环使用对镉形态转化的影响（图 12b），该图为堆叠柱状图与折线图的组合图表，基于 20 mg・kg⁻¹ 镉污染土壤的 5 次循环修复试验数据，展示了 MPS-T 在多次循环使用过程中对土壤镉形态的调控效果：随着循环次数增加，高活性、高生物有效性的可交换态镉（S1）占比显著降低并维持在稳定水平，碳酸盐结合态镉（S2）占比小幅下降，而稳定性更强的铁锰氧化物结合态镉（S3）、有机结合态 / 残渣态镉（S4）占比整体提升。
该研究结果表明，MPS-T 在 5 次循环后仍能持续将土壤中活性镉转化为低毒、稳定的钝化态，不仅验证了材料优异的循环稳定性与镉钝化修复潜力，也为镉污染土壤的可持续修复提供了数据支撑，为开发可重复利用的高效土壤修复材料奠定了实践基础。
